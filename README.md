# site-generator-speed-01-run-20261122

A faster drop-in for makefun-site 1.0.0: `solve.js` exports `run(input)` returning the
same output tree byte for byte, and `main.ts` is the harness entry that answers every
case in `/input/cases.json` into `/output/answers.json`.

Optimisations: single-pass Markdown rendering without token objects, bulk inline
escaping, per-build slug/date caches, word counting without match arrays, and templates
compiled to functions.
